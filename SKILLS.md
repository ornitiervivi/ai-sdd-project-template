## Uso

Leia a skill aplicável antes de executar tarefa especializada. Se múltiplas skills forem aplicáveis, use a menor combinação suficiente.


## Relação entre papéis e skills

Os papéis de `AGENT_ROLES.md` determinam quais skills devem ser consultadas antes de tarefas especializadas. Quando um papel for selecionado, leia a skill correspondente quando existir e aplique suas regras junto com a documentação SDD.

| Papel | Skills mínimas a considerar |
| --- | --- |
| Product Analyst | `.skills/sdd/SKILL.md` |
| Solution Architect | `.skills/sdd/SKILL.md` e compatibilidade aplicável |
| Backend Engineer | `.skills/java-spring/SKILL.md` quando a stack for Java/Spring |
| Frontend/Mobile Engineer | `.skills/frontend/SKILL.md` |
| Database Engineer | `.skills/database/SKILL.md` |
| AI/Voice Engineer | `.skills/sdd/SKILL.md` e `.skills/security/SKILL.md` quando houver dados sensíveis ou IA externa |
| Security Reviewer | `.skills/security/SKILL.md` |
| DevOps Engineer | `.skills/devops/SKILL.md` |
| QA/Test Engineer | `.skills/sdd/SKILL.md` e skills da stack sob teste |
| Code Reviewer | `.skills/code-review/SKILL.md` |
| SDD Scribe | `.skills/sdd/SKILL.md` e `.skills/bug-learning/SKILL.md` quando houver bugs ou incidentes |

Se não houver skill específica para um papel, use `AGENT_ROLES.md`, os arquivos SDD e a compatibilidade aplicável como fonte de regras.
