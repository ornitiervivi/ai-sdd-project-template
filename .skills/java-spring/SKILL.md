# Skill — Java/Spring

Use esta skill em tarefas Java/Spring.

## Regras obrigatórias

- Não usar `record`.
- Não adicionar comentários no código.
- Não fazer mudanças não solicitadas.
- Aplicar Clean Code, Clean Architecture, SOLID e design patterns adequados.
- Usar inglês para todos os nomes de código, pacotes, APIs, DTOs, entidades, propriedades, schemas, migrações e documentação técnica.
- Não misturar idiomas no código ou nos contratos técnicos.
- Cobrir 100% das linhas e 100% dos branches com testes unitários nas classes de regras de negócio.
- Quando alterar uma classe, manter a classe completa, consistente e compilável.
- Usar nomes expressivos em vez de comentários.
- Manter métodos pequenos, coesos e com baixa complexidade.
- Tratar nulidade de forma segura.
- Preferir objetos a listas longas de parâmetros.
- Usar bibliotecas que removam boilerplate e mantenham classes e métodos menores, como Lombok, collections utilities, `StringUtils`, `Objects` e equivalentes, quando compatíveis e justificadas.
- Controllers finos; regras em domínio ou aplicação.
- Repositórios não devem conter regra de negócio.

## Validação sugerida

- Build.
- Testes unitários e de integração.
- Relatório de cobertura confirmando 100% de linhas e branches nas classes de regras de negócio.
- Análise estática quando configurada.
