# Skill — Frontend

Use esta skill para interfaces web ou mobile.

## Regras

- Priorizar acessibilidade, responsividade e clareza visual.
- Separar componentes, estado e serviços.
- Evitar lógica de negócio complexa em componentes.
- Usar design system quando existir.
- Validar estados de carregamento, erro, vazio e sucesso.
- Executar lint, typecheck e testes quando disponíveis.
