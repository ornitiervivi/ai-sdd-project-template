# Skill — Project Bootstrap

Use esta skill ao iniciar um projeto a partir deste template.

## Processo

1. Definir contexto em `PROJECT_CONTEXT.md`.
2. Escrever `SPEC.md` inicial.
3. Escolher stack e preencher `.compatibility/`.
4. Definir arquitetura inicial.
5. Criar backlog em `TASKS.md`.
6. Definir validações em `VALIDATION.md`.
7. Registrar decisões iniciais em `DECISIONS.md`.

## Restrição

Não implemente produto real durante o bootstrap sem especificação aprovada.
