# Skill — Database

Use esta skill para modelagem, consultas e migrações.

## Regras

- Entender casos de uso antes de modelar.
- Preservar integridade e invariantes.
- Criar migrações pequenas e ordenadas.
- Planejar rollback ou mitigação.
- Avaliar índices, locks, concorrência e volume.
- Documentar decisões em `DECISIONS.md`.
