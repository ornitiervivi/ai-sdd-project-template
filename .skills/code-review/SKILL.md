# Skill — Code Review

Use esta skill antes de entregar alterações.

## Checklist

- Escopo mínimo.
- Requisito atendido.
- Testes adequados.
- Documentação atualizada.
- Compatibilidade preservada.
- Segurança revisada.
- Complexidade baixa.
- Nomes expressivos.
- Erros tratados.
- Sem mudanças não solicitadas.
