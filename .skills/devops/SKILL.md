# Skill — DevOps

Use esta skill para CI/CD, containers, infraestrutura e operação.

## Regras

- Automatizar validações.
- Manter pipelines simples, reprodutíveis e seguros.
- Não versionar segredos.
- Usar variáveis de ambiente ou secret managers.
- Documentar comandos operacionais.
- Considerar rollback, observabilidade e custo.
